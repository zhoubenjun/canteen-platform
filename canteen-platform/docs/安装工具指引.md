# 食堂管理数据平台 — 安装工具指引

本项目需要以下运行环境。**本仓库已随附 MySQL 便携版**，其余依赖需按本机情况准备。

## 一、必备工具清单

| 工具 | 版本 | 用途 | 是否已随附 |
|------|------|------|-----------|
| JDK | 17（需 ≥8） | 运行 Spring Boot 后端 | 否，需安装 |
| Maven | 3.6+ | 编译打包后端 | 否，需安装 |
| Node.js + npm | 14+（建议 18/20） | 构建前端 | 否，需安装 |
| MySQL | 8.0 | 数据库 | ✅ 已随附（`tools/mysql-8.0.37-winx64`） |
| Nginx（可选） | 任意 | 生产部署静态产物 | 可选 |

## 二、MySQL 使用说明（已随附便携版）

便携版无需安装、无需管理员权限，位于 `tools/mysql-8.0.37-winx64`。

### 首次初始化（本仓库已初始化并导入数据，可跳过）

```powershell
# 1. 初始化数据目录（仅首次）
$mysql = "D:\canteen-platform\tools\mysql-8.0.37-winx64"
$data  = "D:\canteen-platform\tools\mysql-data"
& "$mysql\bin\mysqld.exe" --no-defaults --initialize-insecure --basedir=$mysql --datadir=$data

# 2. 启动服务（后台）
Start-Process "$mysql\bin\mysqld.exe" -ArgumentList "--no-defaults","--basedir=$mysql","--datadir=$data","--port=3306","--console" -WindowStyle Hidden

# 3. 设置 root 密码为 root
& "$mysql\bin\mysql.exe" -uroot -e "ALTER USER 'root'@'localhost' IDENTIFIED BY 'root';"

# 4. 导入数据库结构+种子数据
& "$mysql\bin\mysql.exe" -uroot -proot --default-character-set=utf8mb4 -e "source D:/canteen-platform/sql/init.sql"
```

> 若本机已有 MySQL（`mysql --version` 可执行、3306 端口已监听），也可直接使用本机 MySQL：
> 执行 `sql/init.sql` 建库建表即可；若 root 密码不是 `root`，在 `backend/src/main/resources/application.yml`
> 中修改 `spring.datasource.username / password`（或启动时设置环境变量 `MYSQL_USER / MYSQL_PASSWORD`）。

### 每次启动 MySQL

```powershell
$mysql = "D:\canteen-platform\tools\mysql-8.0.37-winx64"
$data  = "D:\canteen-platform\tools\mysql-data"
Start-Process "$mysql\bin\mysqld.exe" -ArgumentList "--no-defaults","--basedir=$mysql","--datadir=$data","--port=3306","--console" -WindowStyle Hidden
```

停止 MySQL：结束 `mysqld` 进程即可。

## 三、JDK / Maven / Node 安装指引（若本机未装）

- **JDK 17**：Oracle 官网或 [Adoptium](https://adoptium.net) 下载 JDK17，安装后配置环境变量 `JAVA_HOME` 与 `PATH`。
- **Maven 3.6+**：[Apache Maven](https://maven.apache.org/download.cgi) 下载二进制包解压，配置 `MAVEN_HOME`，`PATH` 加入 `bin`。
- **Node.js**：[nodejs.org](https://nodejs.org) 下载 LTS 版本，安装后自带 `npm`。
