# 食堂管理数据平台 — 使用说明

> 技术栈：Spring Boot + SpringMVC + MyBatis + MySQL（后端）｜ Vue 2 + Element UI + JavaScript + CSS（前端，构建为静态文件由后端托管，前后端不分离）
> 界面语言：中文（简体）｜ 风格：暖色系 ｜ 最小支持宽度：1366px

---

## 一、登录访问

启动后浏览器访问：<http://localhost:8080>

浏览器标签标题为「食堂管理数据平台」。顶部为各功能模块 Tab（菜品库管理 / 食材价格管理 / 周食谱管理 / 食材汇总采购 / 菜品公示），右上角含「大屏展示」入口。

---

## 二、模块 1：菜品库管理

- **菜品卡片**：三列紧凑布局，文字信息在上、图片在下。未上传图片时按类别显示默认占位图（鲜荤/冻荤/主食/素菜各一张）。
- **编号自动排列**：新菜品编号从 1 自动递增，列表按编号排序。
- **成本核算**：在页面顶部设置「食材入口率、劳务费比例、其他费用比例、调料费/份」；系统按「食材价格 × 配料克重」计算食材成本，自动加调料费、劳务费、其他费用，再除以入口率得到**建议售价**（上下取整）。
- **排除调料**：煮鸡蛋、豆浆、馒头等无需调料的菜品可勾选「排除调料」，则该菜不加 0.5 元调料费。
- **审核价格对比**：录入审核价后与建议售价对比——差距 10% 内不提示；高 10% 显示「↑卖贵了」；低 10% 显示「↓卖低了」；超过 50% 提示「⚠异常」。
- **配料管理**：每菜可添加多个配料，配料用**下拉选择食材**（防止名称不一致），并输入克重。
- **筛选**：按类别筛选；「有配料未定价」；按某一天食谱已选的菜品（可区分早/中/晚）。
- **导入导出**：导出菜品 Excel；导入 Excel 时支持菜名、类别、配料（`名称:克重|名称:克重`）、图片文件名等列；支持上传菜品图片（自动压缩至 800px/0.8 质量）。

## 三、模块 2：食材价格管理

- **食材信息**：名称、类别、供应商、规格（仅参考）、单价、单位、计价单位、单位克重。分页展示。
- **价格录入**：选择「计价单位」（元/kg、元/斤、元/个、元/瓶、元/L）后点「按规格自动计算」，自动换算 `单位克重`（元/kg→1000，元/斤→500…）。采购计划单位统一为 KG。
- **批量导入**：Excel 导入，类别/供应商不存在时自动创建，界面布局不变形、按钮可见。
- **批量删除**：支持勾选删除、一键清空全部（均二次确认）。
- **分类 / 供应商管理**：弹窗维护，可新增/删除。
- **价格修改日记**：新增/修改/删除价格自动记录食材名、原价、新价、涨幅、时间；可按食材、类别、供应商、时间范围、操作类型筛选；可导出 Excel。
- **单食材价格历史**：最高价、最低价、平均价、变动次数 + 折线趋势图（ECharts）。
- **统计**：涨价次数、降价次数、平均涨幅、涨幅最大食材。
- **价格历史版本**：可将当前全部食材价格存为快照版本，可载入往期版本（覆盖当前价并记日记），支持删除。

## 四、模块 3：周食谱管理

- 一周 7 天 × 早/中/晚三餐，每餐可添加多个菜品；每餐设置用餐人数（可空/0，支持 1000–3000 及以上）。
- **份数计算**：中/晚餐按「一人吃 2 菜」分配（1100 人 10 菜 → 每菜约 220 份，自动均摊）；早餐中馒头/面条算一人（份数=人数），豆浆/鸡蛋/烤肠等不算（默认 0，可手改）。
- **人数/份数输入框**去掉加减号与上下翻按钮，数字完整显示。
- **添加菜品**：弹窗勾选，每次打开自动清空上次勾选。
- **复制功能**：每个星期行可「复制前一天 / 复制后一天」。
- **模板**：保存为模板（默认名称=当周周一日期），历史模板列表、一键加载、重命名、删除、搜索。
- **导入导出**：周食谱 Excel 导入/导出。
- **自动编排**：设置每餐计划人数、每人打菜数、荤/素/主食配比；可设是否允许重复及最小重复间隔；随机抽取、按权重分配、向上取整份数；预览→确认应用→可换一组。
- **重复颜色区分**：一周内重复菜品 1 次正常、2 次黄色、3 次以上红色，并显示「第 X 次」标签。
- **打印**：可设列宽、勾选打印某几天/某餐次；只打印预览内容不打印背景。
- **周序号**：公历自然周 / 学期周（设置开学日期为第一周，一年两个学期）。
- **吸顶**：向下滚动时星期标题固定吸顶。
- **操作栏**整合为下拉菜单（导入导出 / 模板管理 / 更多操作）。

## 五、模块 4：食材汇总采购

- 根据本周食谱和每餐份数汇总所需食材；可勾选星期（只汇总某天/某几天）。
- 按食材汇总总重量（统一 KG）；按供应商分组生成各供应商采购计划；按食材价格估算采购总金额。
- 早餐/中餐/晚餐分别汇总，也可合并汇总。
- 可保存采购计划到 MySQL，历史计划可回看；导出采购清单 Excel。

## 六、模块 5：菜品公示

- **每日食谱公示**：16:9 固定比例，三栏（早/中/晚，早餐晚餐两列窄），标题「郧西县职业技术学校每日食谱」可修改，标题后显示日期；默认不公示价格，配料小字号展示；可勾选展示配料/审核价/建议售价/图片背景；排版紧凑一屏看全。
- **整周公示**：勾选星期，一键全选/取消全选。
- **打印公示**：可打印整周或某一天，只打印编号与菜名。
- **大屏展示**（右上角或 URL `?mode=bigscreen` 进入）：
  - 暖橙渐变背景，色彩鲜艳；
  - 顶部：食堂名称、日期、时间、餐次下拉、日期下拉（并排）、设置、暂停、退出；
  - 中间菜品卡片网格：有图模式 80% 图片 + 20% 暖棕文字区（菜名 + 审核价），无图模式显示完整信息；审核价大号亮黄色醒目，取消份数显示；
  - 自动轮播分页，每页数量可配置（4/6/8/10/30），每页卡片大小一致，最后一页不足留空位；左右箭头 + 底部圆点指示器，鼠标悬停暂停；
  - 可配置显示：编号/菜名/配料/类别/建议价/审核价/成本/图片；
  - 快捷键：ESC 退出、空格暂停、方向键翻页。

## 七、通用规则

- 所有数据存储在 MySQL 中；支持导出 Excel 备份、导入恢复。
- 所有删除操作均有二次确认。
- 操作成功/失败均有 toast 提示。
- 表单必填项有标识与校验。
- 图片自动压缩：菜品 800px/0.8；健康证 1200px/0.75、头像 400px/0.75（接口已预留对应规格）。
