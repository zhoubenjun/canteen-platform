# 食堂管理数据平台 🍚

面向学校食堂的管理数据平台：菜品库、食材价格、周食谱、汇总采购、菜品公示（含大屏展示）。

- **技术栈**：Spring Boot + SpringMVC + MyBatis + MySQL（后端）；Vue 2 + Element UI + JavaScript + CSS（前端，构建为静态文件，前后端不分离）
- **界面**：中文 · 暖色系 · 响应式（最小 1366px）· 顶部导航 Tab
- **数据**：全部存储于 MySQL，支持 Excel 导出备份 / 导入恢复

## 快速开始

1. 安装 JDK 17、Maven、Node.js（详见 `docs/安装工具指引.md`）。MySQL 8 请自行安装，并用 `sql/init.sql` 初始化 `canteen` 库（本机便携版位于 `tools/`，该目录不入仓库）。
2. 双击 `start-all.bat` 一键启动（MySQL → 后端 → 打开浏览器）。
3. 或按 `docs/启动步骤.md` 分步启动，访问 <http://localhost:8080>。

## 功能一览

| 模块 | 核心功能 |
|------|---------|
| 菜品库管理 | 卡片三列、成本核算、建议/审核价对比、配料下拉、默认图、筛选、批量导入导出、图片上传压缩 |
| 食材价格管理 | 分类/供应商、价格日记、趋势图、统计、历史版本快照、批量导入导出 |
| 周食谱管理 | 7 天×3 餐、份数计算、复制天、模板、自动编排、重复着色、打印、学期周 |
| 食材汇总采购 | 按星期汇总、按供应商分组、金额估算、采购计划留存、导出清单 |
| 菜品公示 | 每日 16:9 公示、整周公示、打印、大屏轮播展示 |

## 目录

```
sql/      数据库初始化脚本
backend/  Spring Boot 后端 + 前端构建产物
frontend/ Vue 前端源码
docs/     使用说明 / 安装指引 / 启动步骤
tools/    本机工具链（JDK、MySQL 便携版与数据库文件，已在 .gitignore 中排除）
start-all.bat       一键启动（MySQL → 后端 → 浏览器）
restart.bat         快速重启（代码未改动时用）
rebuild-restart.bat 修改代码后完整重建并重启（推荐）
kill-backend.ps1    清理所有后端 java 进程（可选）
```

## 修改代码后如何重启

- 只改配置 / 想重新启动：双击 **`restart.bat`**。
- 改了任何前端或后端代码：双击 **`rebuild-restart.bat`**（自动：前端构建 → 重新生成默认图片 → 后端打包 → 启动）。
- 详细分步与手工命令见 `docs/启动步骤.md`。
